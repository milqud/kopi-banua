## Deskripsi
Landing page untuk UMKM kedai kopi. Menampilkan profil usaha,
daftar menu dan harga, jam buka, galeri, form pemesanan, dan lokasi.

## Teknologi
- HTML5 semantik - CSS3 (Flexbox & Grid) - JavaScript (vanilla)

## Fitur
1. Navigasi lengket dan menu navigasi responsif
2. Tata letak responsif pada tiga breakpoint (ponsel, tablet, desktop)
3. Validasi form pemesanan dengan JavaScript
